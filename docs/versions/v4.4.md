# 4.4 · 高对比玻璃（aura 光场）

日期：2026-10-25

## 问题

用户反馈这一版 UI 有大问题：

1. **四角是方的** —— 排查确认真机窗口的 DWM 圆角一直是生效的
   （`DwmGetWindowAttribute(DWMWA_WINDOW_CORNER_PREFERENCE)` 读回 `2 = round`），
   方角来自 `--render` 截图：`RenderTargetBitmap` 渲染的是窗口内容本身，
   不包含 DWM 圆角，所以所有文档截图四角都是方的，用户看到的"方角"即来自这里。
2. **玻璃完全看不出来** —— 4.2 的极简壁纸（近白渐变）和近白的玻璃面板
   亮度几乎一致（差 6 个亮度单位），而且背景没有任何中尺度结构，
   14px 的磨砂模糊"抹不平"任何东西，玻璃和贴纸没有区别。

## 修法

### 截图补真实圆角
`SaveSnapshot` 渲染后再用 `DrawingVisual` + `RectangleGeometry(8, 8)` 裁一次
（与 Windows 11 DWM 圆角同半径），PNG 四角透明，文档与真机一致。

### aura 光场壁纸（新默认）
`tools/gen_wallpaper.py` 新增 `aura` 风格并设为默认：

- 浅色：periwinkle→azure 的饱和中明度底（`#8FA9EE → #5C6EC2`），
  亮白/青/玫瑰三处大光斑 + 右下一处深色压重。
- 深色：深海军底 + 亮蓝/紫/青三处光斑。
- **关键**：叠加两层多倍频明度云纹（46px ±4%、130px ±5%，无结构无方向）。
  原来的光斑尺度都在几百 px，10~14px 的磨砂模糊前后没有差别；
  有了中尺度细节，玻璃内外的"磨平"差才第一次真正可见。

### 面板提亮 + 投影加深（Palette.Light）
- `GlassStrong/Medium/Soft`：24/33/17% 白 → 47/52/46% 白；
  `GlassTopA/B/C` 同步上调。面板在高对比底色上必须亮一档才浮得起来。
- 投影 `PanelShadow` 20/4/0.24（`#14274E` 蓝调），`TabShadow/FloatShadow` 同步加深。
- `WindowBase` 兜底色改为 `#7E93E2`（壁纸加载失败时也是 aura 底色）。
- 磨砂 `Blur` 默认 10 → 14。

### 账号列表裁切修复
4.3 的 `MaxHeight=80` 会把第三行账号切成两半；窗口加高后空间充足，
放开到 `134`，3 个账号完整显示，无内部滚动条。

## 量化验证
- 面板比背景亮 **+21** 亮度单位（4.3 时是 -6，几乎不可分）。
- 玻璃内能看到背景云纹透过（透，而不是磨成一片白）。
- 截图四角 alpha=0（真圆角）。

测试 7/7，tag `v4.4.0`。


## 4.4.1 补丁：卡片圆角本体

用户截图指出「最近活动」卡片左上角是方卡片上画一道圆弧。
根因是 4.3 的模板重构：`Border.CornerRadius + ClipToBounds` 只按**矩形**裁切，
不会按圆角裁，磨砂层和染色层仍是方的，只有描边是圆的。
修复：模板根 `Grid x:Name="PART_Root"`，代码在 `OnApplyTemplate` /
`OnRenderSizeChanged` / `CornerRadius` 变化时设置
`RectangleGeometry(rect, radius, radius)` 作为 `Clip`，所有子层统一真正圆角。
