# 4.5 · 热点提权与开机启动兜底

日期：2026-10-26

## 问题（来自用户运行日志）

```
[01:00:46] 无法设置开机启动，请检查系统权限。
[01:00:46] 网络已恢复，正在开启移动热点
[01:00:46] 无法访问移动热点：拒绝访问。
...（每次状态变化都重复）
```

两个故障：

1. **开机启动写入失败**：`HKCU\...\Run` 被安全策略拒绝，原代码只提示
   「请检查系统权限」，没有任何兜底，用户只能每次手动打开。
2. **移动热点拒绝访问**：`NetworkOperatorTetheringManager.CreateFromConnectionProfile`
   在**普通权限进程**中直接抛 `0x80070005`。实测同一台机器上以管理员运行
   PowerShell / .NET 探针调用完全正常（`capability=Enabled`），
   确认根因是**调用进程权限**，不是网卡或系统能力。
3. **日志刷屏**：`NetworkMonitor` 每次轮询都会重试热点并把同样的失败写进日志，
   用户日志里一分钟内出现多次。

## 修法

### 热点按需提权
- `HotspotService` 识别「拒绝访问」，用户主动点击热点按钮时
  `allowElevation: true`：以 `runas` 启动自身子进程
  （`--hotspot-on/--hotspot-off --result=<temp.json>`），UAC 只弹一次，
  子进程执行完把结果写回 JSON 并退出，主进程读取后更新界面。
- 子进程分流放在**单实例互斥体之前**，否则会被主实例挡掉；
  子进程用 `Environment.Exit` 退出，不进入 WPF 消息循环。
- 用户取消 UAC 时提示「已取消管理员授权，热点没有变化」，不当作错误重试。

### 自动热点不打扰
- 后台自动开启**不弹 UAC**。首次拒绝后进入 10 分钟静默期，
  只记一条可操作提示：
  「移动热点需要管理员权限：点击热点按钮可完成一次授权，
  或在设置里「以管理员身份重启」，之后即可自动开启」。
- 同一条热点提示只记录一次（`LogHotspot` 去重），不再刷屏。

### 开机启动双通道
- 先写 `HKCU\...\Run`；被拒绝时**自动退回启动文件夹快捷方式**
  （`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\SudaLink.lnk`，
  通过 `WScript.Shell` 创建，普通用户始终可写）。
- 两条通道都失败才报错，并带上真实原因；关闭时同时清理注册表与快捷方式。

### 设置页
- 新增「管理员权限 / 自动开启热点需要管理员权限」一行，
  提供「以管理员身份重启」按钮，重启后自动热点不再弹 UAC。

## 验证

- 管理员子进程实测：`--hotspot-on` 返回
  `{"Success":true,"Message":"热点已开启，0 台设备已连接"}`，系统热点状态确实变为 On。
- 浅色设置页渲染正常，新增行不挤压布局。
- 单元测试 7/7。

> 环境备注：本会话的工具沙箱会阻止从工作目录内存映射可执行文件
> （`BundleExtractionIOError` / `CreateFileW error 5`），
> 同一 exe 复制到其他目录运行正常，属于工具环境限制，与程序无关。


## 4.5.1 补丁：点叉收进托盘

用户要求点关闭按钮时不要退出，而是最小化到托盘继续守护网络。

- `OnWindowClosing` 改为**无条件**取消关闭并 `Hide()`，
  不再依赖 `CloseToTray` 开关（避免配置被改后意外退出）。
- 首次收进托盘弹一次气泡：「窗口已收进托盘，网络守护没有中断；
  退出请右键托盘图标选择退出」，之后不再打扰。
- 退出只保留托盘菜单一条路径；`_exitRequested` 时才真正关闭。
- 监听 `SessionEnding`，系统关机/注销时放行，不会被托盘逻辑挡住。
- 设置页原开关改为「始终开启」状态说明，避免误导。


## 4.5.2 补丁：托盘图标固定到通知区

用户反馈点了最小化和叉之后「托盘里看不到」。排查发现图标其实已经注册
（`HKCU\Control Panel\NotifyIconSettings` 里有对应 `ExecutablePath`），
但 `IsPromoted` 为空 —— Windows 11 把新图标默认收进了「^」隐藏区。

- 启动时 `TrayIconPromoter` 轮询找到本程序的 NotifyIconSettings 键，
  把 `IsPromoted` 置为 1，并刷新一次图标让任务栏重新读取。
- 托盘图标支持**单击**唤回窗口（原来只有双击）。
- 注意：单文件 exe 的路径必须是稳定路径（本程序固定在 D://SUDANET），
  换路径运行会生成新的托盘项。


## 4.5.3 补丁：关闭按钮直接收进托盘

用户反馈「点叉以后进程直接没了」。虽然 4.5.1 已把 `OnWindowClosing` 改成取消关闭，
但自绘叉按钮仍走 `Close()`，会经过完整的 WPF Closing/Closed 链路，
任一环节（包括 `OnWindowClosed` 的兜底 `Shutdown`）都可能抢先结束进程。

- `CloseWindow` 不再调用 `Close()`，直接 `HideToTray()`。
- `WndProc` 拦截 `WM_CLOSE`（0x0010），覆盖 Alt+F4 / 任务栏关闭 / 系统关闭请求，
  非 `_exitRequested` 时一律隐藏窗口并标记 handled。
- `OnWindowClosing` 保留为第三道保险。
- 实测：UI 自动化点击真实叉按钮 → 窗口 offscreen、进程存活。

### 托盘图标依赖 Explorer 权限

排查中发现托盘注册失败时，`explorer.exe` 处于 **High 完整性**（曾被以管理员重启），
普通权限进程无法向高权限任务栏注册图标。正常重启电脑后 Explorer 恢复 Medium，
图标即可注册；若仍看不到，到 设置 → 个人化 → 任务栏 → 其他系统托盘图标
把 SudaLink 打开。
