# 3.1.0 · 紧凑化、DWM 圆角、细节动效

用户反馈：窗口太大，小工具不该占这么多屏幕；边角太硬；希望"精致一点"。

## 尺寸一档一档往下压

960×660 → **840×562**（Min 780×530）。

不是等比缩小，而是一层层改：

- 侧栏 180 → 164，内容边距 26 → 22
- 卡片内边距 18 → 16，字号整体降一档（正文 13 → 12.5，注释 11 → 10.5）
- 标题栏 40 → 38，按钮高 34 → 32

## 圆角交给 DWM

```csharp
DwmSetWindowAttribute(hwnd, DWMWA_WINDOW_CORNER_PREFERENCE /*33*/, DWMWCP_ROUND /*2*/);
```

在 `SourceInitialized` 与 `StateChanged` 里设置，最大化时切 `DWMWCP_DONOTROUND`。

为什么不自己裁：`AllowsTransparency=true` 会关掉硬件加速、破坏 ClearType，
文字立刻变毛发虚。牺牲整窗渲染质量换一个圆角，不值。Win10 上没有这个属性，自动保持方形。

## 动效（全部纯 XAML Storyboard）

| 位置 | 做法 |
| --- | --- |
| 按钮 / 导航 / 列表项 | 叠一层 `Border` 改 `Opacity`，不用换 Background（换色会硬跳） |
| 开关 | `TranslateTransform.X` 位移 18px，260ms `CubicEase` |
| 输入框聚焦 | 描边 `Opacity` 0 → 1 |
| 日志项 | `Loaded` 事件淡入 240ms |
| 页面切换 | 淡入 + 上浮 8px |
| 状态点 | 外圈 `ScaleTransform` 1 → 2.6 同时 `Opacity` 0.5 → 0，循环 |
| 窗口 | 入场整体淡入 + 内容上移 12px |

代码只新增了 `AnimateIn` / `SoftChange` / `SetPulse` 三个方法，其余全在 XAML 里。

静态校验脚本会把所有 `Storyboard.TargetName` 扫一遍，确认都在同一命名空间内 —— 拼错的
TargetName 在 WPF 里是静默失效，不校验就只能靠肉眼发现某个动画"好像没动"。
