# 4.2.0 · 壁纸改极简：把线条和花纹全部拿掉

## 起因

用户对 4.0 壁纸的评价是「线条有点难看」「换成一个别的类型的简约的壁纸」。

第一直觉是"换一张更好看的壁纸"，但做了四版对照之后才发现问题不在哪张好看，
在于**壁纸根本不该是画面的主角**：

| 方案 | 特点 | 问题 |
| --- | --- | --- |
| 丝绸（原 4.0） | 七条细白丝带，证明"玻璃外清晰、玻璃内模糊" | 440px 宽的窗口里，细丝看着像**划痕** |
| 雾面 mist | 大尺度柔和色块 | 接近，但仍有几团可见的色晕 |
| 光晕 bloom | 中心亮四周沉 | 四角偏暗，"灰" |
| 色阶 solid | 几乎纯色的纵向色阶 | 素，但整屏偏蓝，观感还是"一张彩色背景" |

最后定的方向：**plain（极简）** —— 近白到极浅蓝灰的纵向渐变，
没有线条、没有花纹、没有可辨认的色块，只留极淡的冷色和细颗粒。

## 为什么这样更好看

- **界面回到主角位置**。之前是"一张漂亮的壁纸 + 一个工具"，
  现在是"一个工具，背景只是它站的地方"。
- **文字与玻璃都更轻松**。背景明度高、色阶短，所有文字的对比度都回到设计值附近，
  不用再靠把文字调深去对抗背景。
- **玻璃的职责变了**。之前玻璃要"透出彩色的背景"来证明自己存在；
  现在背景是素的，玻璃靠**边缘高光 + 投影 + 轻微明暗**表达材质，反而更像真玻璃。
- 深色版同思路：`#0E1119 → #131926 → #080B12`，
  是一张中性深灰底，不再有任何极光或丝绸纹理。

## 换壁纸的开关

`tools/gen_wallpaper.py` 现在支持 5 种风格，改一条命令就能整套重出（浅色 + 深色）：

```bash
python tools/gen_wallpaper.py src/SudaLink/Assets plain   # 极简（默认）
python tools/gen_wallpaper.py src/SudaLink/Assets mist    # 雾面
python tools/gen_wallpaper.py src/SudaLink/Assets bloom   # 光晕
python tools/gen_wallpaper.py src/SudaLink/Assets solid   # 色阶
python tools/gen_wallpaper.py src/SudaLink/Assets silk    # 丝绸
```

四个候选方案当时是**同一份真实状态**渲染出来并排对比的（账号、日志、热点都一样），
所以比较的是背景本身，不是别的变量。这套 `--render` 流程以后换皮都该这么用。

## 教训

> **装饰要有，但不要抢戏。**
> 4.0 那套细白丝带在技术上是正确的（它证明了玻璃确实在模糊），
> 但它把一个"技术验证手段"当成了"设计元素"。
> 用户看到的是划痕，不是玻璃。
