# 4.0.0 · 材质重做：让模糊有东西可模糊

3.6 解决了"玻璃确实是模糊的"，但截图交上去还是那句话：

> 「这个玻璃的效果还是没有实现，感觉颜色还是很脏不透。如果技术上实现不了，
> 就采用高斯模糊。再重新设计吧。」

技术早就实现了高斯模糊。问题在**材质本身**：一眼看过去是一片发闷的奶白，
既不像玻璃，也不干净。这版不调参数了，把底衬和染色整套换掉。

---

## 一、先把病因说清楚

把 3.6 的截图逐像素量了一遍，三个数字很说明问题：

| 现象 | 数值 | 结论 |
| --- | --- | --- |
| 壁纸明度范围 | 70% ~ 90% | 全屏都在高明度，**模糊前后几乎没有亮度差** |
| 玻璃染色 | 白色 16% + 顶部再叠 8% | 两层白把背景压成奶白 |
| 面板内外的色差 | ΔRGB < 6 | 玻璃形同虚设 |

一句话：**背景太"平"，染色太"白"**。

---

## 二、壁纸重做

新壁纸（`tools/gen_wallpaper.py`，numpy + PIL）四条规矩：

1. **色相收窄到一条线**：浅蓝 → 天蓝 → 蔚蓝 → 靛蓝 → 蓝灰 → 深灰蓝。
   不再从蓝跨到玫红 —— 互补色模糊后必然是脏灰。
2. **明度拉开跨度**：顶部近白（#F4F9FF），底部压到 #5A6A96。
   这样玻璃内外才有可比较的亮度差，"透"才看得出来。
3. **细节用锐利的白色丝带**：七条窄丝（宽度 0.35% ~ 1% 屏宽），不做大范围柔化。
   于是玻璃外能看清丝的边，玻璃里只剩一团柔光 —— **这是"这块是玻璃"最直接的证据**。
4. **底部压深 10%**：给上浮的卡片一个"地面"，投影才不显得脏。

深色版同一套结构，换成午夜蓝（#070C22 → #2C2663 → #080A1C），丝带强度 0.34。

## 三、玻璃：从一张纸变成一块有厚度的板

### 3.1 染色降下来

`GlassStrong` 16% → 14%，`GlassSoft` 8%，`SurfaceSoft` 40% → 22%。
顶部受光从两段改成三段（`GlassTopA` 38% → `GlassTopB` 10% → `GlassTopC` 3% → 透明），
让"上亮下沉"是一条连续的曲线，而不是一刀切。

### 3.2 加内侧第二道高光

这是这版观感提升最大的一处。原来只有一圈 1px 外缘描边，玻璃像一张纸；
现在**外缘受光 + 内缩 2.5px 的第二道边**，人眼会自动把它解释成"有厚度的边"。

内缘的圆角必须同比缩小，否则圆角处会"飘"出去。为此写了一个转换器：

```csharp
// Controls/CornerRadiusInsetConverter.cs
new CornerRadius(
    Math.Max(0, r.TopLeft - inset), Math.Max(0, r.TopRight - inset),
    Math.Max(0, r.BottomRight - inset), Math.Max(0, r.BottomLeft - inset));
```

### 3.3 模糊半径 13 → 10

模糊太强会把结构糊没，玻璃就退化成磨砂塑料。10 是这套壁纸下"能看出是背景、
但细节确实被磨掉"的临界点。

## 四、选中态：白玻璃胶囊

3.4 的结论"深色底上不能用白色叠加"在浅色主题里正好反过来：
浅色底上白色叠加是**最干净**的做法。

于是导航栏选中项、分段选择、账号列表选中行统一改成**白玻璃胶囊**：

- 浅色：`TabFillA` 72% 白 + `TabEdge` 95% 白描边 + 12px 投影
- 深色：24% 白 + 36% 白描边（在深色上仍然成立，因为深色底本身足够暗）

**红色只留给品牌与危险操作**（主按钮、删除、"当前"标签、选中图标）。
之前两处都用红色系，界面上一片粉，反而没有重点。

## 五、把"空盒子"变成"水面"

日志区原来是一个大卡片，条目少的时候下面一大片空白，像一个空盒子。

三处改动：

1. 头部 / 尾部加柔光带（`BandFill`），把列表"框"起来，空白区域成了内容区而不是盒子内部；
2. 列表加**底部渐隐 `OpacityMask`**（82% 之后淡出），空白处自然过渡到卡片边缘；
3. 字号 11 → 11.5，颜色 `InkSoft` → `Ink`，小字在玻璃上才立得住。

## 六、文字层级整体加深

| Key | 旧 | 新 |
| --- | --- | --- |
| `Ink` | #171B23 | #0F1319 |
| `InkSoft` | #333B45 | #262D37 |
| `Sub` | #5A6472 | #444D5B |
| `Muted` | #78828F | #5C6675 |

玻璃一旦真的透了，背景的颜色就会渗到文字后面。原来按"白底"调的灰，
在蓝玻璃上对比度直接掉一档，必须整体压深。

## 七、验收流程固化

3.2 那次用临时 `--uitest` 分支截图，验完删掉了。这次固化成正式参数：

```bash
SudaLink.exe --theme=light --render=D:/shots
# 渲染 overview / accounts / settings 三页 → 退出
```

`RenderTargetBitmap` 以 2× 分辨率渲染整个 `ContentRoot`，
不受前台窗口、遮挡、注入点击的影响。这一天的视觉迭代基本都靠它：
改一个数值 → 渲染 6 张 → 并排看 → 再改。

## 八、玻璃六条（这一天最后的总结）

1. **模糊要有东西可模糊。** 背景必须同时具备明暗跨度和锐利细节，否则玻璃只是塑料。
2. **别让互补色进同一屏。** 模糊是平均运算，平均互补色 = 灰。这是"脏"的物理来源。
3. **玻璃该提亮，不该压暗。** 但白色染色超过 20% 就发奶白，低于 10% 就丢字，14% 附近是甜点。
4. **厚度靠第二道边。** 一圈描边是纸，两圈平行描边才是板。
5. **选中态用白玻璃，品牌色留给动作。** 满屏品牌色等于没有重点。
6. **先量再改。** 每个"看起来脏"的直觉，最后都能落成一个可以量化的数字差。
