## 关于 3.3 – 3.6 的源码留存

老实交代：**3.3 到 3.6 的源码没有完整留下来。**

这几个版本是当天连续改的，每改一版都直接覆盖了工作目录（只在 3.3 动工前把 3.2 备了一份），
4.0 又是在 3.6 之上继续改的。所以仓库里能打标签、能编译的历史快照只有
**2.0 / 3.0 / 3.1 / 3.2 / 4.0**；3.3 – 3.6 保留的是完整的文字记录和当时的截图。

这是这一天的教训之一：**改大版本前先 commit，而不是改完再想"要不要备份"**。
现在这个仓库已经把这条变成了习惯。
