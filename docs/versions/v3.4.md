# 3.4.0 · 浅色玻璃发灰 → 推翻做深色极光

## 为什么浅色做不出苹果那种玻璃

3.3 的白玻璃在浅色背景上只剩一片灰。查了三个参考项目：

| 项目 | 关键结论 |
| --- | --- |
| `trrahul/glassmorphism-wpf` | 三种玻璃实现，共同点是**玻璃必须有强对比背景才有色渗透** |
| `PerryLuoLab/TechDashboard` | Aurora 主题：深紫 + 青、用**彩色发光替代黑色阴影**、语义色系统、hover 缩放 1.05 |
| `enviGit/net-sentry` | 霓虹 HUD、全息渐变边框 |

三个都指向同一件事：**深色底**。于是整个界面反过来做。

## Midnight Aurora

- 背景：近黑 `#04060C` → `#080A16`，叠靛蓝 / 紫 / 玫红三团极光
  （`#663A5BFF` / `#3D7C4DFF` / `#3DE23A6E`）
- 玻璃：**深色磨砂底 `#5E0B1220`**，而不是白色叠加 —— 只有这样文字才立得住
- `GlassPanel` 新增 `Glow`（Color DP）：模板里一个 420px 径向椭圆，三档 alpha（`0x1E/0x0A/0`），
  状态切换时用 `ColorAnimation` 520ms 平滑过渡。位置放右上（左上有标题，会压字）

## 最重要的一条配色教训

> **任何白色叠加在深色底上都会变成脏灰。**

所以所有"选中态"（底部 tab、分段选择、账号列表）统一改用**品牌红玻璃**
（`#2E~#3DFF4157` + 红色描边），而不是 `#FFFFFF` 叠加。
而且三处必须**一起改**，否则界面上会出现几块灰斑补丁。

## 布局

700 → 620 高（Min 560）。

概览页日志区**去掉卡片壳，改成开放列表**（header 细线 + 列表 + footer 细线）。
理由：套卡片壳时，那一片空白像"空盒子"，是整屏最丑的地方；开放列表的留白直接融进背景。

footer 显示"网关 · 检测间隔 · 条数"做收口。

## 两个实现细节

- 校徽做淡色水印（opacity 0.05）在深色上像**红色污渍**，弃用。
- 620 高时账号页会滚动，系统白色滚动条极刺眼 → 自定义暗色 `ScrollBar` 隐式样式。

## 批量改 XAML 的坑

脚本化替换 XAML 时，如果写成 `assert` + 链式替换，前一条改完会让后一条的匹配串失效。
必须按**当前文件实际值**写匹配串，并逐条容错，不要一条失败就中断。
