# 3.3.0 · 竖版布局与第一版「液态玻璃」

用户要求：整个界面竖过来做成宽版，并研究 iOS 26 那种液态玻璃效果。

## 布局

440×700（Min 400×600）。侧栏彻底废弃：

- 顶部品牌行：校徽 + `SudaLink` + 「苏大校园网」玻璃小标签
- 中部页面区：不再有独立大标题，靠底部标签栏表达当前位置
- 底部：浮动玻璃标签栏（概览 / 账号 / 设置），高度 58，圆角 29

## 系统模糊：此路不通

先试了正统路线，两条都失败：

| 方案 | 结果 |
| --- | --- |
| `SetWindowCompositionAttribute(ACCENT_ENABLE_ACRYLICBLURBEHIND)` | 返回成功，画面上**没有任何变化** |
| `DWMWA_SYSTEMBACKDROP_TYPE = 3`（Mica/Acrylic） | 同样无效 |

这台机器是 Windows 11 Insider 26340，用了独立探针复现，排除调用姿势问题。
窗口合成底色设成透明后仍然是白底。

结论：**这个环境给不了系统模糊**。于是自绘。

## 自绘玻璃的第一版

`Controls/GlassPanel.cs`，模板分七层：

1. 半透明底（Fill）
2. 顶部柔光 / 底部微沉 的线性渐变
3. 边缘高光描边（白 → 透明 → 淡黑）
4. 96px 颗粒纹理（`Assets/grain.png`）
5. 跟随指针的径向镜面高光
6. 投影
7. 内容

配一张自绘"壁纸"：线性渐变 + 4 个径向色斑（蓝/粉/杏/薄荷）+ 一层 17s/23s 缓慢游走的
环境光，让白色玻璃有东西可"透"。

## 两个坑

- **镜面高光的 Canvas**：直接在面板里放一个 380px 的 `Ellipse` 会把面板撑高到 380 ——
  第一次布局"莫名变高"就是这个原因。套一层 `Canvas`（不参与测量）解决。
- **颗粒纹理路径**：`Resource Include` 之后，在资源字典的模板里用相对路径找不到，
  必须写绝对 pack URI：`pack://application:,,,/Assets/grain.png`。

## 结果与问题

玻璃做出来了，但**用户第一反应是"这也太丑了，这个灰白色"**。
根因不在玻璃本身，在于：白玻璃叠在浅色背景上，只剩一片灰。这个判据在 3.4 / 3.5 / 4.0
反复被验证，最后写进了 4.0 的「玻璃六条」。
