# 4.8.0 — 重做玻璃外壳与圆角体系

> 四角的方感治了，玻璃也补上了 liquid-glass-react 的几笔签名效果。

## 动机

4.7.1 为了治 4.7.0 分层透明窗口在四角的白点残留，整个退回「不透明窗口 + DWM 8px 圆角」。
代价是：**外圈只有 8px，内圈卡片却有 12px**，外圈比内圈还尖。整个窗口看起来像摆了个方盒。
版本记录里写「整体比例重新协调」其实是嘴硬——比例没协调，只是大家都圆，错觉。

用户原话：
> 把 GitHub 上那个液态玻璃的项目 Liquid Glass React 的效果实现到我的应用上；
> 同时优化整个应用窗口的圆角，现在整个窗口四角有点丑；
> 可以考虑一下对整个应用界面进行一个新的设计。

GitHub 上的 [`rdev/liquid-glass-react`](https://github.com/rdev/liquid-glass-react) 是 React 实现，
核心是一组 SVG filter + backdrop-filter + 弹性 transform，正好补 4.7.x 留下的几处缺口：
追光边、棱镜色散、悬停顶部光泽、压按弹性——这些 WPF 都能用低开销手段还原。

## 实现

### 1. 窗口外壳：自绘 20px 圆角

`MainWindow.xaml`：
- 窗口改回 `AllowsTransparency="True"`，`Background="#00000000"`（透明黑，
  非白，4.7.0 已验证可以防止四角白点）。
- 窗口里三层：
  - `ShadowHost`：纯圆角矩形 + `WindowShadow` 效果，只画投影，不参与布局。
  - `Shell`：圆角 20 的 Border，`WindowBase` 兜底色。
  - `ShellBody`：Shell 内层 Grid，按 20px 圆角几何裁剪（壁纸才不会在四角露方角）。
- `ShellRim`：1px 渐变光边（上受光、下沉影），上亮下暗——玻璃从外缘"立"起来全靠它。

`WindowFx.cs`：
- 不再设置 `DWMWA_WINDOW_CORNER_PREFERENCE`（圆角自己画）。
- 只保留 `DWMWA_BORDER_COLOR=NONE` 一项：Win11 会在分层窗口上叠一圈 1px 系统边框，
  落在透明留白上就像"应用外面还套了个方框"，必须关掉。

`MainWindow.xaml.cs` `OnWindowStateChanged`：
- 最大化时去圆角、收留白、藏投影，避免最大化后窗口周围出现一圈透明边框。
- `ShellBody.SizeChanged` → `UpdateShellClip()`：尺寸一变就按当前状态重新裁圆角。

### 2. GlassPanel：移植 liquid-glass-react 的几笔签名

实现都在 `Theme.xaml` 的 GlassPanel 模板和 `GlassPanel.cs` 上：

| 特性 | liquid-glass-react | 本实现 |
| --- | --- | --- |
| 追光边（rim light） | 边缘渐变 mask + 鼠标偏转角 135°± | 边缘 1px 渐变 + `RotateTransform` 跟随指针 |
| 棱镜色散 | RGB 三通道 displacement 分离 | 镜圈上一道冷→暖 `LinearGradientBrush`（极淡） |
| 悬停顶部光泽 | radial-gradient + mixBlendMode overlay | `RadialGradientBrush` 顶边居中 |
| 弹性回弹 | elasticity 比例 + scale transform | `ElasticEase` 取代 `CubicEase` |

- 模板新增 `PART_Chroma`（色散环）、`PART_TopGloss`（悬停光泽）、`PART_Edge` + `PART_EdgeSpin`（追光边）。
- `GlassPanel.Chroma` 属性控制色散强度（默认 1，可设 0 关闭）。
- `OnMouseMove` 新增 `UpdateEdgeSpin`：算指针相对玻璃中心的极角，把光边的 `RotateTransform.Angle`
  动画到「指针方向 + 135°」（135° 是梯度的亮端基准角）。`OnMouseLeave` 把角度动画回 0。
- Theme.xaml 新增 `ElasticEase x:Key="ElasticOut"`，替换 Tile/Primary/Ghost 三套模板里压按的
  `CubicEase` —— 24ms 立即按下不变，回弹改成 42ms + 一次振荡。
- `OnMouseEnter/Leave` 多了 `FadeGloss`，让 `PART_TopGloss` 的 `Opacity` 在 0/1 之间淡入淡出。

### 3. 圆角梯度统一

| 元素 | 旧 | 新 |
| --- | --- | --- |
| 窗口 | 8 (DWM) | **20** (自绘) |
| 卡片 | 12 | **14** |
| 瓷片 | 14 | **12** |
| 列表行 | 14 | **12** |
| 输入框/分段/导航 On | 12/17/17 | **10/10/10**（On 是导航胶囊内的高亮块，与 dock 同圆角） |
| 标签 Tag | 8 | **7** |
| 标题栏按钮 | 13 | **14**（更接近正圆） |
| 底部 dock | 22 | **28**（全胶囊） |

后续 GlassPanel 的 `CornerRadius` 属性继续按各处用时给出（11/12/22→14 等）。

### 4. 排版节奏

- 页面左右内边距 18 → 20。
- 状态卡 / 瓷片之间 12 → 14。
- 标题栏高度 48 不变，按钮宽 30 / 高 28 不变，只圆角调到 14。
- 窗口尺寸 460×690 → 488×718，给新圆角留出呼吸空间。

### 5. 调色板新增 key

两个 Palette 都补了：
- `EdgeA/B/C/D`：每个 GlassPanel 一份实例的光边四档色（旧 `Edge` 整 brush 仍保留给老模板用）。
- `GlossTop`：悬停顶部光泽的色。
- `ShellRim`：窗口外缘光边 brush。

### 6. 上机跑图后补的三处修正

代码编译通过、`--render` 出图、真机截屏逐角放大之后，又改了三处——都是只有「真的画出来」才看得见的问题：

**a. 投影在圆角处变成一圈虚线**

真机把右下角放大 10 倍，能看到弧线外侧一圈断断续续的深色小段，像虚线圈。右上角却是干净的。

原因：`WindowShadow` 是 `DropShadowEffect`，`RenderingBias="Performance"` 用低质量方框模糊，
阴影被自身不透明底遮住的那条硬边正好落在 20px 圆弧上，低精度采样把弧切成了小段。
改成 `RenderingBias="Quality"` 后虚线消失，阴影也顺了。窗口小、效果是静态缓存，质量档的开销可以忽略。

**b. 浅色主题玻璃过透、文字发飘**

`BackdropVeil` 原来是 `#00FFFFFF`（完全不遮挡），背景彩团一路透到面板上，
浅色下玻璃面板和背景几乎同亮度，日志行的灰字落在薄荷绿上就糊了。

- `BackdropVeil` `#00FFFFFF` → `#14FFFFFF`：一层极淡白纱压住彩度。
- 玻璃底 `GlassStrong/Medium/Soft` 从 15%/18%/14% 提到 24%/28%/23% 白。
- 控件表面 `SurfaceSoft` 30% → 40% 白、`BandFill` 25% → 36% 白，输入框和条带才有边界。
- `ControlEdge` 上边 40% → 55% 白、下边 8% → 11% 黑，发丝边更立得住。

**c. 底衬壁纸彩度太高**

根子其实在壁纸本身：`tools/make_backdrop.py` 里五个色团 alpha 全在 200–250，
饱和度拉满。玻璃再调也像糊在彩虹上。

给 `build()` 加了 `sat` / `wash` 两个参数，浅色底衬走 `sat=0.58`（降饱和）+ `wash=0.10`（向白提）。
色团仍然有结构、有边界（镜圈要放大的东西还在），但不再抢主角。

## 踩坑

- **`RenderingBias="Performance"` 的投影会在圆弧上变成虚线**（见 6.a）。
  凡是自绘圆角 + 自阴影的组合，先用 Quality 打底，再考虑降档。
- **嵌套 Border 才能既圆角又裁内容**。`Border.CornerRadius` 只圆各层自己的外框；
  内层 Grid（壁纸 + 内容）如果不另外 `Clip`，壁纸会在圆角外露出方角。
  4.4.1 已经踩过一次，4.8 在窗口层级的另一处（ShellBody）再裁一次。
- **Win11 系统边框会叠在透明留白上**。`AllowsTransparency=True` 后，
  DWM 的 1px 边框被透明留白孤立出来——还是那条老的"外面套了方框"。
  这次只关 `DWMWA_BORDER_COLOR` 不再用 `DWMWA_WINDOW_CORNER_PREFERENCE`。
- **`RotateTransform` 在 `LinearGradientBrush.RelativeTransform` 里走最短弧**：
  从 350° 跳到 10° 不能让边光绕大圈，所以 `(target - current + 540) % 360 - 180` 取最短方向动画。
- **不能让 `StateChanged` 自递归**。最大化时改 `ShellBody.Clip` 不会触发 `SizeChanged`，
  所以 `UpdateShellClip` 直接基于 `WindowState` 决定即可，不依赖事件二次通知。
- **`OnWindowStateChanged` 不能在 `ShellBody.ActualWidth<1` 时设 Clip**，
  会写到无效几何；Loaded 钩子再补一次。

## 4.8.1

> 4.8.0 上机的第一天，用户只说了两句：「玻璃效果还是不够通透」、
> 「深色模式下有一层黑色的阴影很丑」。

### 动机

4.8.0 把圆角、外壳、材质都补齐了，但材质本身偏「磨砂塑料」而不是「玻璃」，
深色下每块面板外面还压着一圈黑。截图放大 + 采样像素之后，问题由三处叠加：

1. 模糊半径 7 + `Performance` 档模糊 → 背景被抹成一片均匀色，没有结构，也就不像玻璃。
2. 镜圈宽度 14，在 400px 宽的卡片上是一条很宽的奶白边，像厚塑料包边。
3. 深色投影是纯黑 + 大半径（面板 20px/45%，dock 24px/62%），压在深底上就是一圈脏晕。

### 实现

| 项 | 4.8.0 | 4.8.1 |
| --- | --- | --- |
| `GlassPanel.Blur` | 7 | **4.5** |
| 模糊质量 | `Performance` | **`Quality`**（近似方框模糊会把背景糊平） |
| `GlassPanel.Bezel` | 14 | **9** |
| 深色 `PanelShadow` | 20px / 45% 黑 | **9px / 18%** |
| 深色 `TabShadow` | 14px / 45% | **7px / 20%** |
| 深色 `FloatShadow` | 24px / 62% | **14px / 30%** |
| 深色 `BandFill` | 12% 白（提亮） | **8% 黑**（压暗分隔） |
| 深色 `GlassTopA` | 8.6% 白 | **3.9% 白** |
| 浅色玻璃底 | 24/28/23% 白 | **19/23/18%** |
| 浅色 `SurfaceSoft` | 40% | **37%** |
| 浅色 `ControlEdge` 下边 | 11% 黑 | **22% 黑** |

### 踩坑

- **`BlurEffect` 的 `Performance` 档不是"略差一点"，是换了算法**。它走近似方框模糊，
  半径一小就把有结构的背景抹成均匀色块，玻璃立刻变成塑料。要"通透"必须用 `Quality`。
- **玻璃一薄，控件边界就得自己立起来**。浅色下面板填充从 24% 降到 19% 后，
  输入框（`SurfaceSoft` + `ControlEdge`）几乎整块消失；把发丝边下沿加深到 22% 黑才重新成立。
- **深色卡内的分隔不能靠加白**。深色 UI 里"更亮"等于"更雾"，头部工具条会叠出一层灰白雾；
  改成轻微压暗，层级反而清楚了。
